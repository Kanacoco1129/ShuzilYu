夢向 Meng Xiang 網站修正版

檔案：
- index.html
- style.css
- script.js

請把原本的圖片放進 img 資料夾，檔名必須和 script.js 及設定內容完全一致。
背景音樂請放在 audio/background.wav。

請不要把三份程式碼合併成同一個檔案：
- HTML 只放 index.html
- CSS 只放 style.css
- JavaScript 只放 script.js

在 VS Code 中開啟資料夾後，直接用瀏覽器開啟 index.html，或使用 Live Server。
背景音樂需要使用者點擊按鈕才會播放，這是瀏覽器的自動播放限制。
